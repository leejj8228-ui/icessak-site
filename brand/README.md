# 얼음싹싹 로고

> **확정 (2026-10-07)**: 모서리를 깎은 팔각형(C안). 앞으로 이 파일들을 그대로 씁니다.

앞으로 계속 쓸 로고 파일과 사용 가이드입니다. `index.html`을 열면 가이드 페이지가 보입니다.
미리보기: `preview/desktop.png`, `preview/mobile.png`, `preview/logo.png`

## 뜻

**모서리를 깎은 각얼음(팔각형)** 안에 **두 줄의 빛**과 **반짝임**이 있습니다.
- 깎인 모서리는 잘라 낸 얼음 조각을 뜻하고, 그 변이 두 줄과 같은 45°라 모양이 정돈됩니다.
- 두 줄은 얼음 표면의 광택이면서, **싹·싹** 닦아 낸 자국입니다.
- 반짝임은 청소가 끝난 깨끗한 얼음입니다.
- 글자는 "얼음"을 먹색, "싹싹"을 파랑으로 나눠 "깨끗하게 해 준다"는 쪽에 힘을 줬습니다.

## 파일

| 파일 | 쓰는 곳 |
|---|---|
| `logo.svg` | 기본형(가로). 흰·밝은 바탕, 웹사이트, 문서 |
| `logo-white.svg` | 흰색형. 파란 바탕, 사진 위, 차량·작업복 |
| `logo-mono.svg` | 단색형. 흑백 인쇄, 도장, 영수증 |
| `logo-stacked.svg` | 세로형. 정사각형 자리, 스티커 |
| `logo-mark.svg` | 심볼만. 카카오톡 프로필, 앱 아이콘, 작은 자리 |
| `favicon.svg` | 브라우저 탭 아이콘 |

모든 파일은 SVG(벡터)라 크기를 키워도 깨지지 않습니다. 인쇄소에는 SVG를 그대로 주거나 PDF로 변환해 주면 됩니다.

### PNG (`png/` 폴더, SVG를 못 쓰는 곳용)

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `logo-2000.png` | 2000×496, 투명 | 문서, 블로그, 네이버 플레이스 |
| `logo-white-2000.png` | 2000×496, 투명 | 파란·어두운 바탕 위 |
| `logo-stacked-1200.png` | 1200×1276, 투명 | 스티커, 전단 |
| `logo-mark-1024.png` | 1024×1024, 투명 | 심볼만 필요한 곳 |
| `kakao-profile-640.png` | 640×640, 아이스 바탕 | 카카오톡 채널 프로필 (원형으로 잘려도 안전) |
| `app-icon-512.png` | 512×512, 흰 바탕 | 네이버·구글 비즈니스 프로필 사진 |

## 검토한 모양

둥근 사각형(첫 안), 육각형, 정팔각형, 모서리 깎은 팔각형을 같은 크기로 비교해 모서리 깎은 팔각형으로 정했습니다. 비교 이미지: `preview/shape-compare.png`

## 규칙

- **여백**: 로고 둘레에 심볼 높이의 절반 이상을 비웁니다.
- **최소 크기**: 가로형은 높이 24px(인쇄 약 6mm) 이상. 더 작으면 심볼만 씁니다.
- **색**: 싹싹 블루 `#0B5AD9`, 먹색 `#111A23`, 흰색, 아이스 `#E2EFFA`. 로고 색을 바꾸거나 늘이고 눕히지 않습니다.

## 다시 만들 때

`tools/logo_gen.py`가 로고 SVG 6종을 만듭니다. 모서리 깎는 정도는 `mark()` 안의 `c = 13`, 글자 간격은 `track` 값입니다.

```bash
pip install fonttools
# 첫 인자: Pretendard 패키지가 풀린 폴더의 부모(그 안에 package/dist/public/static/Pretendard-Black.otf), 둘째 인자: 출력 폴더
npm pack pretendard@1.3.9 && tar xzf pretendard-1.3.9.tgz
python3 tools/logo_gen.py . .
```

## 글꼴과 라이선스

로고 글자는 **Pretendard Black**의 글자 모양을 윤곽선(패스)으로 바꿔 넣었습니다. 글꼴이 설치되지 않은 기기에서도 똑같이 보입니다.
Pretendard는 SIL Open Font License 1.1이라 로고를 포함한 상업적 사용이 가능합니다(글꼴 파일 자체를 단독으로 판매하는 것만 금지).

## 한계

- 상표 등록 여부는 확인하지 않았습니다. 정식으로 쓰기 전에 "얼음싹싹" 상호와 로고가 이미 등록된 것이 있는지 특허정보검색(KIPRIS)에서 확인하는 것을 권합니다.
- 사용 예시(명함, 스티커, 카카오톡 프로필)는 화면용 모형입니다. 실제 인쇄 전에는 인쇄소 규격(재단 여백, CMYK 색)에 맞춰 다시 조정해야 합니다. 화면 파랑 `#0B5AD9`는 인쇄에서 조금 탁해질 수 있습니다.
